# ไฟล์ทดสอบ "นำเข้าซีรีย์ยางใหม่" (/tires/import)

สร้างด้วย `node scripts/gen-import-seed.mjs [PREFIX]` (ไม่ใส่ PREFIX จะใช้ `SD` + เดือนวันชั่วโมงนาที)
ไฟล์ชุดที่ commit ไว้ใช้ prefix `SEED1020` — ถ้านำเข้าไปแล้วรอบหนึ่ง ให้สร้างชุดใหม่ด้วย prefix อื่นก่อนทดสอบซ้ำ
ไม่อย่างนั้นทุกแถวจะติด "ซีรีย์นี้มีในระบบแล้ว"

แคตตาล็อกในไฟล์อิงบริษัททดสอบ **GO1 (Go Along co.,Ltd. · Premium)** ณ 2026-10-20
- CHENGSHAN CST-35 11R22.5 16PR (ได้รับสิทธิ์)
- GOODYEAR KMAX S 295/80R22.5, HANKOOK AH35 315/80R22.5 (บริษัทสร้างเอง)
- อื่นๆ ขนาด 11R22.5 16PR / 11R22.5 18PR / 295/80R22.5 18PR / 10.00R20 18PR / 215/70R15
